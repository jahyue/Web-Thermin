#  Web Theremin

An interactive, browser-based musical instrument and real-time audio visualizer inspired by the classic electronic theremin. Built from scratch using the **Web Audio API**.

##  Features

* **Cursor-based controls:** Move your cursor or touch across the canvas to dynamically manipulate musical pitch (Y-axis) and volume (X-axis).
* **Live Oscilloscope Visualizer:** Visuals change based on the waveform; you have the frequency and even to the volume
* **Multi-Waveform:** Switch instantly between four oscillator types: **Sine**, **Square**, **Sawtooth**, and **Triangle**.
* **Musical Feedback:** Displays the active musical note (e.g., *A4*), exact frequency in Hertz, and current volume percentage.
